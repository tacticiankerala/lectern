# Lamplight

A quiet theme for static blogs: one column, generous type, and a dark mode that follows the system.

It shipped in October. It gets a release when the site generator changes, and otherwise needs nothing.

## What it does

- Serif body text at a comfortable measure
- Light and dark palettes, with syntax colours to match
- Reading time and a table of contents for long posts
- No JavaScript

```css
:root {
  --measure: 68ch;
  --ink: #2b2a27;
  --paper: #f8f5ee;
}
```
